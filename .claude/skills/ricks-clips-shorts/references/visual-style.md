# Визуальный стиль: подробный разбор

Разбор сделан по официальным раскадровкам YouTube (кадр ~каждые 0.97 с) для всех 20 роликов и по превью 1080p. Покадрово разобраны: Ancient Jar, Perfect Railroads, Job in Japan, Pirate Cannonballs, Storm Oil, Roller Coasters, Memory, Second Draw.

## 1. Персонаж: анатомия

```
      ___          ← головной убор = роль (самая крупная цветная деталь)
    /     \
   |  • •  |       ← голова: белый/кремовый шар, контур 4–6 px, без носа
   |  ‿   |          глаза-точки, брови-штрихи, рот-линия
    \_____/
    |#####|        ← тело-капсула цвета костюма, детали формы (пуговицы, полоски, галстук)
    |#####|
     /   \         ← ноги-палочки (чёрные линии), ступни без обуви или точкой
```
- Пропорции примерно 1 : 1.3 : 1.5 (голова : тело : ноги). Голова очень большая.
- Руки-палочки появляются из боков тела только когда держат предмет.
- Тело чуть сплюснуто по перспективе: персонаж стоит в 3D-пространстве и отбрасывает реальную тень.
- Второстепенные персонажи (толпа, армия, офис) сделаны той же моделью и различаются цветом тела и шапки.
- Типажи, встреченные в 20 роликах:
  - повар в колпаке;
  - капитан в треуголке;
  - пират в бандане и полосатой рубахе, с попугаем;
  - император в шапке с бусинами;
  - стражник в шлеме-котелке с пером;
  - ковбой в шляпе с усами;
  - шериф;
  - офисный «салариман» и босс с седой прядью;
  - учёный в очках;
  - старатель и богач в белом костюме с цилиндром;
  - рыцарь в латах;
  - монах-продавец индульгенций;
  - король с короной и плащом;
  - полицейский;
  - кассир;
  - детектив в шляпе.

## 3. Окружения и свет

- Стиль: стилизованное 3D с рисованными (painterly) текстурами камня, дерева и ткани, как в современной инди-игре. Мягкий AO, объёмный свет, лёгкий блум, DOF на заднем плане.
- Эпохи: Древний Китай, средневековый замок, Дикий Запад, пиратское море XVIII века, американская железная дорога XIX века, японский офис, американский пригород 50-х, луна-парк, шахта, тюрьма, неоновый город-антиутопия.
- Палитры по настроению:
  - **день:** ярко-синее небо с пушистыми мультяшными облаками, насыщенная зелень и красно-оранжевые скалы;
  - **ночь:** глубокий синий и фиолетовый, большая полная луна, тёплые оранжевые факелы и окна;
  - **закат / финал:** розово-оранжевое небо, контровое солнце, длинные тени;
  - **интерьер:** тёплые лампы, красные ковры, золото (дворец) или холодный офисный свет с зелёной стеной (Япония).
- Детали: на экран попадают «говорящие» надписи-вывески (FIRST LINE IN GETS IT ALL!, HOT SHOT, CARCASS, Pardons, OUR WINNERS, газета THE CLICKETY CLACK LINE!, календарь NOV FRI 11). Это способ показать контекст без слов.

## 4. Камера: каталог приёмов (с примерами)

| Приём | Когда | Пример |
|---|---|---|
| Push-in на лицо | реплика, мысль героя | император «burst laughing» |
| Сверхкрупный план предмета | деталь-загадка | шар во рту дракона; зазор в рельсе на уровне шпалы |
| Low angle | герой бросает вызов, антагонист давит | босс «his face goes purple» |
| Top-down | показать схему или расстановку | маятник внутри кувшина с восемью стержнями |
| POV предмета | вовлечь зрителя | из-за ствола пушки на берег; экран телефона «Inbox (0)» |
| Широкий кран / дрон | масштаб, «весь город», армия | строй армии перед дворцом; каньон |
| Whip-pan со смазом | переход между локациями | скалы каньона «растягиваются» в полосы |
| Slow-motion + частицы | удар, взрыв | щепки от ядра, ковбой падает в пыль |
| Срез / X-ray | объяснение механизма | пласты земли с молнией разлома; путь вагонетки со светящимся следом |
| Пропуск времени | смена главы | день → ночь с луной → утро; календарь |
| Реакция в финале | точка истории | ухмыляющийся герой на фоне грибовидного облака |

Темп: новый план на каждую смысловую группу из 2–4 слов. Стоп-кадров и статичных планов дольше 2 с нет, камера всегда немного плывёт.

## 5. Субтитры: спецификация

- Шрифт: жирный округлый гротеск (Montserrat Black / Gilroy Heavy / Nunito Black).
- Белая заливка, чёрная обводка 6–8 px, мягкая тень вниз.
- Размер ≈ 5–6 % высоты кадра.
- Позиция: центр по X, ≈ 62–70 % по Y (ниже лица персонажа, выше нижнего UI Shorts).
- 1–2 слова, смена строго по голосу, без анимации-подпрыгивания (или с минимальным pop-in).
